# The Science of Chhau Dance

### An interactive eBook by Arnav Ajana

[![Release verification](https://github.com/ArnavAjana/PreserveChhau/actions/workflows/release.yml/badge.svg)](https://github.com/ArnavAjana/PreserveChhau/actions/workflows/release.yml)

**The Science of Chhau Dance** is a source-linked, interactive introduction to Chhau for new learners. It begins with Mayurbhanj Chhau, the tradition through which I first encountered the form, and studies it alongside Seraikella and Purulia Chhau.

The project brings movement, music, masks, costume, history, place, and evidence into one reading experience. It does not treat the three regional traditions as interchangeable. When sources disagree, the disagreement stays visible.

UNESCO inscribed Chhau dance on the Representative List of the Intangible Cultural Heritage of Humanity in 2010. The inscription covers all three traditions. PreserveChhau is an independent project. It does not claim UNESCO review, endorsement, or permission to use the UNESCO emblem. See the [official UNESCO Chhau record](https://ich.unesco.org/en/RL/chhau-dance-00337).

> I started this project after performing Mayurbhanj Chhau and realising how difficult it was for a beginner to find clear, connected information. This is the guide I needed when I began.

## How to use the eBook

- **Read as a spread or a single page.** Wide screens show a two-page book layout. Smaller screens use one broad page.
- **Open the contents panel.** Jump to a chapter, the atlas, a glossary, the timeline, or the source library.
- **Search the book.** Find a place, person, instrument, movement term, or idea.
- **Use the glossary.** Hover over an underlined term, focus it with a keyboard, or tap it on a touch screen to see its meaning.
- **Follow citations.** Numbered citations take you to the matching source in the Library.
- **Inspect a 3D prototype.** Load a model only when needed, then rotate, zoom, change the light, and compare viewpoints. Read the description beside each viewer before drawing a conclusion.
- **Use the atlas controls.** Search the documented records, select a marker, inspect its evidence, and stop or restart the globe rotation. Rotation starts automatically unless your device requests reduced motion.

## The Map of Chhau

The atlas begins with the three regional heartlands:

- Mayurbhanj in Odisha
- Seraikella in Jharkhand
- Purulia in West Bengal

It also records UNESCO's 2010 inscription and ten documented performance venues. The complete set contains three heartland anchors, one UNESCO documentary milestone in Nairobi, and ten venues. Nairobi marks the committee decision, not a Chhau performance or resident tradition.

Each venue needs a source which names both Chhau and the venue. The map does not treat general Indian arts activity, an unverified tour, or a diaspora presence as proof of a Chhau performance. Baripada is shown as an important Mayurbhanj centre, not a proven origin point.

The current atlas contains 14 evidence-backed records. It is a documented set, not a claim to every place where Chhau has been performed.

UNESCO's inscription covers all three regional traditions. The decision was adopted during the fifth session of the Intergovernmental Committee in Nairobi. See the [official UNESCO Chhau record](https://ich.unesco.org/en/RL/chhau-dance-00337).

The travelling light beams are interface cues. A beam links a venue to a heartland only when the source states the same regional style. It does not prove an origin, journey, lineage, influence, or historical route.

## About the 3D models

The reader includes 17 recovered GLB files distributed across eight relevant pages. They are static, generated, generic visual prototypes with no recorded source pose, performer, maker, lineage, rig, animation, regional attribution, or practitioner review. They help a reader practise:

- rotating and viewing a form from several angles
- comparing silhouette, balance, spacing, and negative space
- testing light, camera position, and scale
- noticing the limits of a frozen digital pose

The prototypes are not evidence of a Chhau movement, costume, character, weapon, formation, or regional tradition. Each model appears with a description which states what is visible and what the file does not prove.

The model set is about 509 MiB, so the repository download is unusually large. Models load inside the reader only after you choose one.

The separate [3D study roadmap](./CHHAU_3D_MODEL_ASSET_REQUEST.md) defines 23 future studies. A future cultural model needs a named source, clear permission, full credit, regional review, and approval from the relevant practitioner, musician, maker, or troupe before publication.

## Read the evidence carefully

This project follows five rules:

1. Keep Mayurbhanj, Seraikella, and Purulia material with the region named by its source.
2. Distinguish documented fact, interpretation, community memory, and an open question.
3. Show disagreement instead of forcing uncertain histories into one answer.
4. Credit dancers, teachers, musicians, makers, researchers, photographers, and institutions.
5. Remove or withhold media when permission or provenance is incomplete.

The source library contains 22 numbered source records. Citations remain attached to the relevant pages so readers can check a claim and continue beyond the eBook.

## Learning and safety boundary

This eBook supports observation and research. It does not teach formal Chhau technique and does not replace a practitioner.

The physical activity drafts for readers aged 8 to 14 have not received final review from a pediatric movement and safety professional or a current Chhau practitioner. Do not learn low stances, leaps, falls, acrobatics, masked movement, or weapon phrases from the screen. Use trained supervision and an appropriate setting.

## Run locally

Use Node.js 22.12 or newer.

```bash
git clone https://github.com/ArnavAjana/PreserveChhau.git
cd PreserveChhau
npm ci
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). On a Mac, you can also double-click `Start-PreserveChhau.command` after extracting the repository.

## GitHub Pages deployment

Every push to `main` runs `.github/workflows/release.yml`. The workflow verifies the manuscript, atlas, TypeScript, lint, rights records, and production build. It then exports the complete static site and deploys it to GitHub Pages.

The deployment reads its public URL and base path from GitHub. This keeps the routes, photographs, atlas, decoder files, and 17 GLB prototypes working at the project URL or a configured custom domain.

Repository administrators must set **Settings → Pages → Source** to **GitHub Actions**. A `CNAME` file alone does not configure a custom domain for an Actions deployment.
